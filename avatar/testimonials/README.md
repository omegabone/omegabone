# Testimonial Transcripts — Avatar Project

Verbatim student testimonial transcripts feeding the Digital Twin / Avatar knowledge base
(`Avatar/OMEGA_DIGITAL_TWIN_MASTER.md` in Drive).

## Why verbatim

These are real students' words used in marketing. Transcripts are captured verbatim —
filler words may be trimmed, nothing else. Never paraphrase a quote into a stronger claim
than the student made, and never generate a quote that was not said.

## Filling a transcript

Each file mirrors that student's interview question set from Drive, in order. Paste each
answer under its question, replacing `_[transcript]_`. Then:

1. Pull 3–5 verbatim quotes into the **Pull Quotes** table with timecodes.
2. Write **Avatar Notes** — the before-state language the student used *unprompted*, the
   objection they named, and the transformation they led with. This is the part the Avatar
   actually consumes; it's what keeps copy in the customer's language instead of ours.
3. Flip **Status** at the top of the file to `TRANSCRIBED`.
