Choose the folder your clips are in

The page reads the videos from that folder and copies the ones you approve into an approved folder inside it. Nothing is uploaded — the files never leave this machine.

Clip metadata — topic, caption, quote — comes from the extractor’s manifest.json. Keep a copy in the same folder and it is picked up automatically.

Keyboard

  • J / K next / previous clip
  • A approve R reject U undecided
  • Space play / pause
  • N jump to the next undecided clip
  • F write feedback, Esc to leave the box
  • ? this list
