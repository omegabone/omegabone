Start it with the launcher

This page reviews the batch your extractor last wrote, and plays the lesson videos it cut the clips from. A page opened straight from the filesystem cannot reach either, so it has to be started rather than double-clicked on its own.

Double-click Review clips.command in this folder — or run: 

cd tools/clip-review
node bin/review.mjs --video-dir ~/Videos/lessons

Keyboard

  • J / K next / previous clip
  • A approve R reject U undecided
  • Space play the clip from its in-point
  • [ / ] nudge the in-point, Shift for the out-point
  • N jump to the next undecided clip
  • F write feedback, Esc to leave the box
  • ? this list
